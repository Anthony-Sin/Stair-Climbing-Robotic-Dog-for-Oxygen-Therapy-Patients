### Skills to Know About
- [ ] /model — Switch the active Claude model. The team's most-used command; pick a model to match the task (heavier for design/debugging, lighter for quick edits).
- [ ] /plan — Enter plan mode to design an approach before touching code. Used heavily here for working through robot behavior and sim changes before editing.
- [ ] /clear — Reset conversation context between unrelated tasks. Used often to keep long sim/debug sessions from bleeding into each other.
- [ ] /effort — Tune reasoning effort up or down for the task at hand.
- [ ] /voice — Dictate prompts by voice instead of typing.
- [ ] /compact — Compress the current context when a session gets long but you want to keep going.
- [ ] /code-review — Review the current diff for bugs and cleanups before pushing.
- [ ] /verify — Run the app and confirm a change actually works (note: this team verifies via log files, not by running the sim — see Team Tips).
